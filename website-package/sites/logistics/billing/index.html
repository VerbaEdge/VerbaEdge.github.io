Important boundaries

Documentation software is not regulated payment or tax infrastructure.

French electronic invoicing

For covered French domestic B2B transactions, the national reform requires an approved platform. A PDF or VerbaEdge document template is not a substitute. Any future integration must use an authorized provider and confirmed specifications.
